Instalación en Wix
El motor de escritura: 2 pasos. No necesita Velo, ni Secrets, ni funciones de servidor.
Paso 1 — Insertar el HTML
Editor Wix → Añadir → Embed → HTML personalizado (iframe) → pega TODO el contenido de este archivo. Publica el sitio.
Paso 2 — Tu clave de Gemini
Abre el Escritorio publicado, escribe el PIN, y en la barra de arriba pega tu clave en el campo Clave Gemini y pulsa Activar. Queda guardada en tu navegador. Ya puedes generar.

¿Sin clave? aistudio.google.com/app/apikey → Crear clave. Sirve tanto AQ. como AIza.

Si al generar sale 401/403: entra a console.cloud.google.com → "APIs y servicios" → habilita Generative Language API en el proyecto de esa clave. Esa es la causa real, no el formato.
Diagnóstico
En la Etapa 4 pulsa ⚡ Probar conexión. HTTP 200 — la clave SIRVE = todo listo. Si sale otro número, el mensaje crudo de Google dice exactamente qué falta.

B — Código de página
Activa Velo (Dev Mode). En el código de la página donde está el Embed, pega esto. Cambia #html1 por el ID real de tu elemento HTML (clic en el Embed → Propiedades → ID):
// Codigo de pagina (la pagina del Embed)
import wixData from 'wix-data';

$w.onReady(function () {
  $w('#html1').onMessage(async (ev) => {
    const m = ev.data;
    if (!m || m.tipo !== 'guardarEscrito') return;
    const d = m.datos;
    try {
      const item = {
        titulo: d.titulo, cuerpo: d.cuerpo,
        extracto: d.extracto || '', slug: d.slug || '',
        ambito: d.ambito, formato: d.formato || '',
        tags: d.tags || '', estado: d.estado || 'borrador',
        fechaEscrito: new Date()
      };
      const res = await wixData.insert('Escritos_' + d.ambito, item);
      $w('#html1').postMessage({ tipo: 'escritoGuardado', ok: true, id: res._id });
    } catch (err) {
      $w('#html1').postMessage({ tipo: 'escritoGuardado', ok: false, error: err.message });
    }
  });
});
Publica. Al pulsar "Guardar en Wix" verás la confirmación con el ID aquí mismo.
